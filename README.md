# BanditVault Store

**Android app store for BanditVault apps**

BanditVault Store is an Android app that lets you browse, download, and update BanditVault applications. Get access to exclusive apps not available on Google Play with automatic update notifications.

## 📲 Download & Install

**Latest Version:** 1.0.8 (Build 4)  
**Download:** [BanditVault Store APK](https://store.banditvault.co.uk/api/apps/banditvault-store/download)

### Installation Steps

1. **Download** the APK to your Android device
2. **Enable Unknown Sources**
   - Go to Settings → Security
   - Enable "Install from Unknown Sources" or "Install Unknown Apps"
   - Select your browser and allow installations
3. **Install** - Open the downloaded APK and tap Install
4. **Open BanditVault Store** and start browsing apps

## ✨ Features

- **Browse Apps** - Discover all available BanditVault applications
- **One-Tap Installation** - Download and install apps instantly
- **Automatic Updates** - Get notified when updates are available
- **Download Progress** - Real-time progress indicators for downloads
- **App Categories** - Browse by Social, Games, Tools, and more
- **Modern Interface** - Clean Material Design 3 with dark theme
- **Fast Loading** - Instant startup with smart caching

## 📋 Requirements

- Android 5.0 (API 21) or higher
- ~50 MB storage space
- Internet connection

## 🔄 Updating Apps

1. Open BanditVault Store
2. Tap the **Updates** tab at the bottom
3. See all apps with available updates
4. Tap **Update** to download and install the latest version

Updates are detected automatically - you'll see an "Update Available" badge on apps that have newer versions.
